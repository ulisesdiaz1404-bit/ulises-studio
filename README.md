# Ulises Studio

Web personal de Ulises Diaz — desarrollador web freelance.

Portafolio + mini-CRM privado (clientes, ingresos) + formulario de cotización para nuevos clientes.

## Tecnologías

- HTML, CSS, JavaScript vanilla
- Chart.js para visualización de ingresos
- LocalStorage para persistencia de datos
- FormSubmit.co para envío de consultas por email
- Sin frameworks ni dependencias pesadas

## Estructura

- `index.html` — markup
- `style.css` — diseño editorial dark con paleta gold/amber
- `script.js` — lógica de CRUD, lock screen y animaciones
